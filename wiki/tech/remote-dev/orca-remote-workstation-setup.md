# Orca 远程工作站与终端协同架构

## 一、架构设计与工作原理
Orca 是现代高效开发者终端与多工作区管理工具。结合局域网/Tailscale，可实现“轻薄笔记本客户端 ➔ 高性能 Linux 工作站”的无缝远程工作流。

## 二、配置与实操要点
* **远程服务暴露**：在 Linux 服务器上通过 Tailscale / LAN 开放 SSH 终端通道；
* **本地客户端挂载**：Orca 客户端通过 SSH Remote Tunnel 直接连接服务器端的工作目录；
* **优势**：
  * 计算与编译全部发生在服务器端（保持低电量消耗与强劲算力）；
  * 本地 UI 渲染保持原生流畅度，网络抖动不影响后台持续任务运行。
