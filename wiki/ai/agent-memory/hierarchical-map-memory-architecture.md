# Agent 分级地图长期记忆系统架构 (Hierarchical Map Memory)

## 一、第一性原理与核心困境
在构建自主 AI Agent 的长期记忆时，行业普遍面临三大死穴：
1. **上下文爆炸与污染**：若把所有历史或 Skill 描述塞进 Context，Token 消耗呈指数膨胀且干扰推理；
2. **检索幻觉与慢查**：扁平化 RAG 或庞大向量库在面对特定个人偏好、本地资产时容易产生语义漂移；
3. **原始会话堆积 (Raw Dump)**：保存数万字原始对话会导致信息密度极低，Agent 重读成本极高。

## 二、架构设计哲学与三大支柱

### 1. 记忆库 (Memory) 与 知识库 (Wiki) 物理隔离
* **客观知识 (Wiki)**：面向外部世界的工程架构、算法、研报与技术事实，采用领域化知识沉淀；
* **主观记忆 (Memory)**：面向用户画像、交互铁律、踩坑经验与本地实体资产（IP/服务/Token），采用高频卡片沉淀；
* **隔离价值**：从根本上杜绝查个人资产时在浩瀚知识库中产生检索噪音。

### 2. 分级地图寻路导航机制 (Hierarchical Map Navigation)
借鉴地理认知模型，将检索复杂度从 $O(N)$ 降低为 $O(\log N)$：
* **第一层（全国总地图 `INDEX.md`）**：仅几十行，定义一级领域地图入口（系统画像、金融投资、学科、基础设施、元认知）；
* **第二层（领域地图 `<domain>/README.md`）**：列出该领域下的子分类与专题说明；
* **第三层（具体知识条目）**：直达单文件并装载，**全程零全库扫描，零冗余上下文开销**。

### 3. 睡眠提炼法 (Sleep Distillation)
模拟人类睡眠期大脑对海量白昼信息的重构：
* 剔除所有寒暄、试错与中间推导；
* 仅将**最终达成共识的 3~5 条高密度断言、决策或参数**归档入库。
