# 4. Syncthing 电脑+手机MöbiusSync 最简同步教程（Tailscale已通）

## 两台电脑

1. 两台打开 WebUI 127.0.0.1:8384，右上角显示ID，互相复制ID
2. A添加B的ID，B添加A的ID，显示已连接
3. A新建文件夹，填写文件夹ID，共享给B
4. B接受并选择本地路径，自动双向同步

> 不用填IP，文件夹ID两边必须一致，双向同步

## 电脑 ↔ MöbiusSync 手机

1. 电脑、手机互相复制设备ID
2. 电脑加手机ID，手机加电脑ID
3. 手机添加文件夹，
- 文件夹标签：起个名字
- 文件夹路径不要写，选下面的 Pick External Folder，可以选择Obsidian目录下的目录作为同步m目录
- 切到共享的那一栏，选择机器
4. 电脑端打开网页，把 8384 那个端口的网页点接受，然后在里面可以配置电脑端的


> 不用填IP，文件夹ID一致，双向同步，手机需保持前台运行
